# DDL

**Paper:** DDL: A Dataset for Deepfake Detection and Localization in Real-World Scenarios  
**Paper:** https://arxiv.org/abs/2506.23292

DDL includes image, video, audio, spatial-localization, and temporal-localization
tasks. The current AIDE implementation supports only whole-image binary
classification, so the first compatible experiment will use the DDL-I image
subset.

DDL evaluation is postponed until the GenImage and OpenFake experiments are
complete.
